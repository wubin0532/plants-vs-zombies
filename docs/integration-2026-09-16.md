### 性能短测

每档 240 帧，统计丢弃前 20 个样本。45 株植物、120 只僵尸、25 个资源保持稳定；关闭新增波次和自然资源，植物高血量、攻击冷却延后。开启寒风，测量真实 Phaser WebGL 循环。

| 档位 | 规则均值 | 场景更新均值 | 渲染调用均值 / P95 | 帧间隔均值 / P95 |
|---|---:|---:|---:|---:|
| 1440×1050，高画质 | 0.18 ms | 0.63 ms | 4.41 / 4.60 ms | 16.67 / 17.10 ms |
| 844×390，低画质 | 0.19 ms | 0.60 ms | 5.01 / 5.70 ms | 16.67 / 16.80 ms |

场景更新包含规则耗时；渲染是 CPU 调用计时，不是 GPU 时间。两档均在同一台桌面电脑运行，小视口不代表手机真机性能。此前空样本性能结果作废。
