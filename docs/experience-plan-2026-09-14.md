## 第二批：体验深化

1. 三星评价：每关按"不丢车 / 用时 / 剩余阳光"评星，地图格显示星级（store 增加 stars 字段，存档版本升级）。
2. 分层配乐：低音 pad 常驻 + pressure>0.6 淡入鼓点 + 最终波旋律层，复用 audio.ts 现有 pressure 参数。
3. 种植音按类型区分（蘑菇噗、坚果咚、爆炸物引信）。
4. 图鉴加"对策"字段：僵尸弱点与推荐植物（content.ts 加字段，图鉴展示）。
5. 新手引导分级：前三关分步提示（选卡→种植→收阳光），后续关卡不再显示。
6. 结算数据小结：用时、击杀数、剩余阳光、丢车数 + 随机鼓励语。
7. 种子卡交互：拖放种植、阳光不足红闪、格子幽灵预览、Shift 连种。

## 第三批：留存体系

1. 每日挑战：固定种子 + 限定卡池 + 本地最佳成绩（引擎已支持种子）。
2. 成就系统：累计击杀、零损通关、全三星等，主页展示。
3. 商店（金币消费闭环）：卡槽扩展、一次性道具、皮肤。
4. 无障碍：高对比度/色盲友好、UI 字号档位。
5. 移动端打磨：种子栏横滑、触控热区 ≥44px。
