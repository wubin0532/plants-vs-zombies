## 实施细则

### 动作
- 步行以脚步接地与移动距离配合为目标，不以简单提高帧数代替动作设计。
- 先打磨豌豆射手、向日葵、坚果、普通僵尸、铁桶与樱桃，再扩展到其余角色。
- 小幅受击只影响展示，不以震屏或停顿改变战斗规则。
- 增加渲染插值；低刷新率仍保持规则结果稳定。

### 音效
- 爆炸需要起音、冲击与余响；不同植物使用独立音色。
- 高频音效变体、轻微音调变化；爆炸优先于普通射击。
- 音乐、环境、战斗、界面分别控制；总输出避免削波。
- 素材需来源明确；若仍使用合成素材，应如实标注，不能标成录制配音。

### 全屏
- 浏览器支持时调用原生全屏；不支持时使用沉浸布局。
- 不承诺隐藏不允许控制的手机浏览器系统栏。
- 菜单按钮保留可发现性，刘海和底部安全区不遮挡交互。

| 项目 | 处理 |

| 残留特判 | 移除第 3-5 关僵尸 40% 生命／体型的遗留设定，该关回到正常强度 |
| 波次 | 间隔 32 秒 → 30 秒；单波基数 `2.2 + 章节 0.75 + 关卡 0.2`；进度曲线 `0.62 + 0.78p + 0.85p²`；末三波 ×1.7、倒六波 ×1.2；同波内间隔按关卡从 0.8 秒压到 0.4 秒 |

### 地块贴图偏移与种植预览（2026-09-15 增补）

| 问题 | 根因 | 处理 |
| --- | --- | --- |
| 月下墓园看不到墓碑（罐子、冰道、弹坑同理） | `terrainCache` / `fogCache` 用 `add.renderTexture(0,0,1200,690)` 创建；`RenderTexture` 继承 `Image`，默认原点是中心，整张 1200×690 贴图向左上偏移半张，地块都被画到屏幕外（迷雾也盖错位置） | 显式 `setOrigin(0,0)`；地块贴图降到 `depth 0.5`（压在植物、僵尸之下）；迷雾按格铺满不再留缝 |
| 墓碑辨识度低 | 原来的灰绿色圆角块和夜间草坪接近 | 改为浅色石碑 + 深色描边 + 影子 + 十字 |
| 种植预览“只看得到一半、不清楚” | 预览透明度只有 0.5；`setTexture` 会把显示尺寸重置成贴图原始尺寸（食人花等尺寸不一致）；尺寸也没跟随角色体型 | 预览透明度 0.82，外加一层白色光晕提示落点，尺寸改为与种植后一致（`plantScale`） |
| 从卡片拖到草坪不出结果 | 卡片里的 `<img>` 默认可以原生拖拽，浏览器接管拖动后游戏收不到 pointerup；且拖动过程中种子并未被选中 | 卡片 `@dragstart.prevent` + `draggable="false"`；按下卡片即选中（`seedDown`），抬手落在草坪直接种植（`pointerup` 里用 `downElement` 区分点选与拖拽），再点一次取消选中和 Shift 连种保持不变 |

验证：168 项自动测试通过，生产构建通过；Chromium 实测 2-1 三块墓碑可见、4-1 迷雾正确覆盖右侧 5 列、拖动预览跟随指针并在落点成功种植。
