# 动画、图片与音效交接

本任务负责图片、动画与音效。最初交付集中在表现层；本次按用户要求补齐 engine.ts 中的图片/声音事件与前后发射起点，其余战斗规则交由另一位 AI 处理。原有未提交改动保留。

## 已交付

- 28 张原创透明插画，每张同时提供可编辑 SVG 和无损 WebP：`public/assets/presentation/`。涵盖全部现有飞行弹丸家族、黄油、玉米炮弹、篮球、首领冰火球、阳光金币及状态图标。
- 49 种植物、26 种僵尸保留现有角色图片；既有 6 套序列图集、其余分部件动画继续使用。新增植物出场伸展、爆炸植物蓄势、漂浮、风叶摆动、磁力脉动、墙体裂纹、休眠、照明与盾牌表现，以及蹦极下降、潜水、车辆尘土、解除武装和魅惑提示。不是 75 套重新手绘的逐帧动画。
- 弹丸按类型显示孢子、尖刺、瓜体、星星等；旋转、尾迹、抛物线保留独立表现。发射口旧的通用绿色碎片已替换。
- 植物发射声按攻击家族区分；僵尸共享基础发声并对巨人、小鬼等调整音高；五种场景具有不同音乐音阶和环境层。暂停/停止后取消尚未完成解锁的发声请求。
- `public/assets/audio/`：110 个可直接试听/复用的 PCM WAV，包含 49 个植物声音入口、26 个僵尸声音入口、25 个通用事件、5 个场景环境、5 个音乐音色样本。共享音色的角色可能生成相同文件，并非 110 段独立录音。音乐 WAV 是音色样本；游戏中的音乐由 GardenAudio 动态编排，不把样本当完整循环曲目。
- 本地验收页 `art-review.html`：全部角色和图片目录、受伤/冰冻/特殊动作、45 项快捷试听。隔离 Engine，不读写玩家存档。

## 启动验收

```sh
npm run dev
```

打开开发服务器的 `/art-review.html`。此页仅作为 Vite 开发验收入口，没有加入玩家首页或正式生产页面。游戏的图片、音效和渲染功能已经接入正式代码。

## 本次文件边界

- `src/game/presentation.ts`：纯表现适配器、图片清单、状态姿态。
- `src/game/scene-class.ts`：加载/显示插画、动作叠加、声音场景参数。
- `src/game/engine.ts`：本次追加只涉及效果事件类型/source、Effect.direction、按前后方向生成出膛起点；没有改多发数量、攻击间隔、伤害、黄油随机规则。
- `src/game/audio.ts`、`src/game/audio-catalog.ts`：合成声音和稳定声音 ID。
- `src/game/presentation-preview.ts`、`art-review.html`：本地验收工具。
- `scripts/prepare-presentation.mjs`：重建 SVG/WebP；执行 `node scripts/prepare-presentation.mjs`。
- `scripts/export-audio-playwright.js`：离线声音导出配方，作为 Playwright CLI `run-code` 的函数文本使用，下载到 `output/pvz-audio.zip`。需先打开本项目开发服务器，再将 ZIP 解压到 `public/assets/audio/`。使用相同 GardenAudio 合成配方，单声道 22050Hz/16bit，移除末尾静音。
- `tests/presentation.test.ts`：图片完整性、类型映射、纯表现不修改实体、音色分类。

## 给战斗逻辑 AI 的接入约定

### 弹丸

直接使用现有 `Shot.type`，下列类型已准备：

| type | 图片 |
| --- | --- |
| pea / repeater / three / split / gatling | 豌豆 |
| snowpea / icepea | 冰豌豆 |
| puff / scaredy / sea / spore | 紫色孢子 |
| cactus / needle | 仙人掌刺 |
| cattail / homing | 追踪尖刺 |
| cabbage | 卷心菜 |
| kernel | 玉米粒 |
| butter | 方块黄油 |
| melon / winter | 西瓜 / 冰西瓜 |
| star | 星星 |
| fire | 火球 |
| cob | 玉米炮弹 |
| basketball / snowball | 篮球 / 冰球 |

也支持可选 `visualType` 覆盖图片，例如 `{type:'kernel', visualType:'butter'}`。规则层需要自行扩展 Shot 类型声明。表现层不会按伤害数值猜测弹种。

- 真正连发：由规则层创建不同 uid 的独立 Shot。表现层一条 Shot 只画一颗，不会伪造额外子弹。可选 `delay > 0` 表示尚未出膛，此时隐藏；递减/发射/取消队列由规则层负责。
- `hit = true` 不再显示；Shot 移出数组后自动回收图片对象。
- 黄油：发射前确定 `type:'butter'` 或 `visualType:'butter'`；伤害、概率、定身由规则层处理。当前旧引擎在命中时才决定黄油，暂时仍只会产生玉米粒图片。
- 杨桃轨迹、追踪、防空、穿盾、射程、溅射和火炬增伤全部交给规则层。本次仅根据现有位置和类型绘制。

### 动画状态

沿用现有 Plant 的 `age / attackAge / hp / max / sleep / ready / timer / digest / chomp`，Zombie 的 `age / actionTime / motion / hp / armor / freeze / ally / disarmed / jumped / jump / special / underground / flying`。

- 每次真实出膛将植物 `attackAge = 0`，这样每一颗连发都能带动后坐。
- 生命周期与时间推进由规则层负责。表现层使用游戏时钟，暂停时不继续旋转、闪烁或播放动作。
- 解除武装目前显示状态图标；除了已有的路障、铁桶、铁门卸甲外，未重绘所有角色的无装备全身图。

### 声音事件

继续调用 `engine.sound(kind, x, source)`。新增 kind：`needle / star / butter / magnet / wind / coin / splash`。

- 尖刺：`needle`，source 为 cactus/cattail。
- 星星：`star`；黄油：`butter`。
- 磁力成功：`magnet`；吹风：`wind`；金币拾取：`coin`；水花：`splash`。
- 爆炸必须传 source（cherry/jalapeno/potato/doom/cob），已有独立配方。
- 每颗实际发射的声音由引擎派发，合成器不会把一次发射自动演成多发声音。
- 本次已接入：磁力成功 magnet、金币收集 coin、三叶草 wind、海草 splash、窝瓜 smash。传入 type="butter" 的弹丸已使用黄油图片与发射声；何时产生黄油由逻辑 AI 完成。
